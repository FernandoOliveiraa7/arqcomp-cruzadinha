# arqcomp-cruzadinha.
Atividade avaliativa 3,  Sprint 3
Cruzadinha de Arquitetura Computacional

Jogo de cruzadinha que roda no navegador (HTML, CSS e JavaScript puros) para treinar os termos de Arquitetura Computacional.

Jogue aqui: https://SEU-USUARIO.github.io/arqcomp-cruzadinha/

Como jogar
Leia as pistas em Horizontais e Verticais; os números batem com os do tabuleiro.
Clique numa casa e digite as letras (sem acento e sem espaço). Clique de novo na mesma casa para alternar entre horizontal e vertical. As setas do teclado também movem o cursor.
Clique em Conferir para ver quais palavras estão certas (verde) e erradas (vermelho) e o contador de acertos.
Clique em Reiniciar para limpar o tabuleiro.
Palavras e pistas (16 palavras)
Resposta	Pista
MICROCONTROLADOR	Chip único com processador, memória e portas de entrada e saída, usado em sistemas embarcados.
RAM	Memória de trabalho volátil: perde o conteúdo quando a energia acaba.
FLASH	Memória não volátil regravável, apagada em blocos, comum em pen drives e SSDs.
DUALCORE	Processador com dois núcleos de execução no mesmo chip.
ADDRESSBUS	Via que leva da CPU a posição de memória a ser lida ou escrita.
REGISTRADORES	Pequenas memórias dentro do processador, as mais rápidas, que guardam dados em uso imediato.
CPU	Cérebro do computador: busca, decodifica e executa as instruções dos programas.
QUADCORE	Processador com quatro núcleos de execução no mesmo chip.
ULA	Parte da CPU que faz as contas e as operações lógicas.
ROM	Memória não volátil gravada na fabricação, com conteúdo fixo que o usuário não altera.
EEPROM	Memória não volátil regravável, que apaga e escreve byte a byte, usada em pequenos dispositivos.
CACHE	Memória pequena e muito rápida entre processador e RAM, guarda dados usados com frequência.
DATABUS	Via que transporta o conteúdo trafegado entre CPU, memória e periféricos, nos dois sentidos.
DMA	Mecanismo que move dados entre periféricos e RAM sem passar pela CPU.
MEMORIADEMASSA	Guarda arquivos e programas de forma permanente, como HD e SSD, em grande capacidade.
UC	Parte da CPU que interpreta instruções e coordena os demais componentes.
